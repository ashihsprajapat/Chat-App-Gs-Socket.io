# 💬 Real-Time Secure Messaging Platform

A full-stack **real-time chat and calling application** that enables **one-to-one messaging**, **audio/video calls**, and **media sharing**, built with modern web technologies. Designed for speed, security, and a seamless user experience.

---

## 🚀 Features

- 🔒 **Secure Authentication** using **JWT** and **bcrypt**
- 💬 **Real-Time Messaging** powered by **Socket.IO**
- 📞 **Instant Audio & Video Calls** with **Simple-peer (WebRTC)**
- 🖼️ **Media Sharing & Profile Uploads** via **Cloudinary Integration**
- 🌓 **Dark / Light Mode Toggle** for enhanced user experience
- 👥 **User Profiles** with personalized avatars
- ⚙️ **Scalable Architecture** using **MERN Stack**

---

## 🛠️ Technologies Used

**Frontend:**
- React.js  
- Context API / Redux (state management, optional)
- Socket.IO Client  
- Simple-peer  
- Tailwind CSS (or your chosen UI library)

**Backend:**
- Node.js  
- Express.js  
- MongoDB (Mongoose ODM)  
- Socket.IO  
- JWT Authentication  
- bcrypt (for password hashing)

**Cloud Services:**
- Cloudinary (media storage and optimization)
